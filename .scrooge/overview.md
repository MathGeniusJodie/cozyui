**Cozyui** is a pixel-art desktop environment for Linux/X11 that bundles a terminal emulator, todo list, AI chat, radio alarm clock, battery indicator, calendar, prize wheel, and live budget countdown into a single framebuffer-rendered application.

The architecture centers on a 16-color indexed palette (loaded from `na16-1x.png`) whose `Index` values flow through a pipeline: each widget owns a sub-framebuffer that is composited onto the root framebuffer at dynamically computed positions, then a precomputed `PresentLut` converts indices to BGRA for shared-memory presentation to X11. `Paint::Checker` dithering for the background is anchored to destination coordinates so overlapping widgets mesh seamlessly, and `Graphics::Swap` allows per-draw index remapping for tints and silhouettes. The desktop background sprite (`desk.png`) is stretched horizontally via a tri-panel mapping (left edge, tiling center, right edge) to fill any window width. Layout is fully dynamic: `sync_dynamic_layout` recomputes all widget positions on every frame, and the window resizes to match whenever any widget's dimensions change. The eight widgets—Puter (alacritty terminal), Toodle (todo), Fwends (AI chat via OpenRouter), Twirl (prize wheel), Wavey (radio alarm clock via mpv/IPC), Fizzle (battery candle), Day (calendar), and Budgit (budget countdown)—are dispatched by a `WidgetId` enum whose `ALL` array must stay manually synchronized with the `WIDGET_COUNT` constant. Budgit is the newest widget, reading a dated expense config (`budgit.conf`) and a ledger CSV (`budgit.csv`) to integrate piecewise burn rates and display a live "money left" countdown with color-coded urgency.
