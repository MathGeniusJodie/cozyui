**Cozyui** is a pixel-art desktop environment for Linux/X11 that bundles a terminal emulator, todo list, AI chat, and radio alarm clock into a single framebuffer-rendered application.

A shared `graphics` crate provides the low-level pixel pipeline: sprite blitting with palette remapping (locked to the 16-color NA-16 palette), bitmap font rendering with word-wrap, and PNG decoding through `memmap2` + the `png` crate. The terminal (`puter`) integrates `alacritty_terminal` for VT100 semantics but draws every cell with the project's own pixel font and color palette, keeping the entire UI visually cohesive. The AI chat (`fwends`) streams completions from OpenRouter via libcurl subprocess calls, manages a JSON chat history, and renders scrolling message bubbles entirely in software. Every module shares a common input layer built on `xkbcommon` for keyboard layout handling and `x11rb` for raw X events, with mouse interaction translated from pixel coordinates back into text-caret positions through helper functions in `text_edit`/`text_input`. The critical invariant is that all rendering stays on the CPU in a single `Framebuffer`; no OpenGL, no XDraw, no compositing — the shared-memory image is blitted to the window in one operation, which keeps the codebase portable to any surface that can accept raw pixels.
